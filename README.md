Руководство пользователя

Данный математический тренажер создан для тренировки решения примеров!

Примеры являются лёгкими и простыми, программа позволяет решать математические примеры в игровой форме и тренировать вычислительные навыки.

Главная цель - решить 4 примера на разные действия за 30 секунд!

Интерфейс:

1. При запуске программы пользователь видит главную страницу, на которой расположены 4 примера на разные действия и строку таймера. Вместо чисел на данном этапе вставлены знаки вопроса.

   <img width="483" height="393" alt="image" src="https://github.com/user-attachments/assets/2903d5a3-ea3d-4a2a-86cd-19252d2121cd" />

2. Чтобы запустить тест ,нужно нажать на кнопку "Start the Quiz".

   <img width="478" height="385" alt="image" src="https://github.com/user-attachments/assets/038be5b1-b1dc-466f-b192-4b4cb48545e5" />

3.При запуске программы пользователь видит ,что вместо знаков вопроса теперь рандомные буквы ,с которыми пользователь должен сделать определённые действия за 30 секунд.
